Empty templates prepared on 2026-11-07. No values below represent actual outcomes. Use 'Not collected' for missing observations; use zero only when measured and genuinely zero. All timestamps should include date and India time (UTC+05:30).

## Private operational log fields

Keep the following raw records outside Git when identifiable. Use internal IDs and collect only what is necessary.

| Record | Fields |
| --- | --- |
| Recruitment | Participant/vendor ID, role, broad area, channel, agreed participation period, consent reference, joined/declined/withdrawn, reason if freely offered |
| Selling session | Vendor ID, declared date/start/end, update receipt/publication times, status, source, expiry, self-initiated/shared reminder/individual prompt, handled-session outcome |
| Availability audit | Audit ID, vendor ID, planned/actual time, original claim and timestamp, expiry, serving correct/incorrect/unknown, item stock separately, cause, correction time |
| Visit follow-up | Optional participant ID, vendor ID, visit week/time, consultation before visit, claimed information, sought item bought yes/no/unknown, reminder category, failure cause |
| Operator effort | Date, category, vendor-specific/shared, minutes, allocation method, onboarding versus recurring, cash expense if any |
| Incident | ID, date, affected claim, impact, correction, unresolved question, withdrawal/removal handling without sensitive details |

No direct identifiers are needed in public reports. Do not publish raw records just because names have been removed; combinations of location, time and quotations can identify someone.
